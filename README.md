# Student Management CRUD

A simple full-stack Student Management System built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

This project allows users to add, view, update, and delete student records.

## Features

- Add new students
- View all students
- Edit student details
- Delete students
- MongoDB database integration
- REST API
- Form validation
- Error handling
- Responsive frontend
- GitHub version control

## Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- Fetch API

### Backend

- Node.js
- Express.js
- Mongoose
- CORS
- dotenv

### Database

- MongoDB

### Tools

- VS Code
- Git
- GitHub
- Thunder Client
